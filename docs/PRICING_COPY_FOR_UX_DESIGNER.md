## DESIGN NOTES FOR UX DESIGNER

### Color Coding
- **Beta/Free:** Use green accent (`#10B981` or similar success color)
- **Post-Launch Pricing:** Use neutral gray (`#6B7280`)
- **Urgency:** Use amber/orange (`#F59E0B`) sparingly

### Typography
- **Pricing amounts:** Use largest heading size with bold weight
- **"Forever" or "per month":** Use smaller, lighter weight for contrast
- **Feature lists:** Use checkmarks (✅) for visual scanning

### Layout
- **Pricing cards:** Side-by-side on desktop, stacked on mobile
- **Beta card:** Slightly elevated or highlighted (border, shadow, or background)
- **CTAs:** Primary CTA should be high contrast, impossible to miss

### Mobile Considerations
- **Pricing table:** Convert to accordion or card stack on mobile
- **Feature lists:** Collapse with "Show more" on mobile if needed
- **CTA buttons:** Full-width on mobile for easy thumb access

### Accessibility
- **Color contrast:** Ensure WCAG 2.1 AA compliance (4.5:1 minimum)
- **Focus states:** Visible keyboard navigation indicators
- **Screen readers:** Add aria-labels for pricing amounts and CTAs
